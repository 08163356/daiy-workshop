# 从日记到行动的教练闭环

很多 AI 对话停在“听起来有道理”。Daily 的教练模式尝试把反思连接回真实行动。

## 闭环

1. 从日记、笔记或澄清问题进入教练会话。
2. 服务端注入来源摘录和未完成跟进项。
3. 教练按 GROW 思路推进，一次只问一件事。
4. 结束时沉淀洞察、承诺、复查日期和核对问题。
5. 用户确认后把承诺转成待办。
6. 待办完成时关闭跟进项；下一次会话先回看上次承诺。

```mermaid
flowchart LR
  journal[日记或笔记] --> coach[一次一问的教练对话]
  coach --> commitment[可验证的行动承诺]
  commitment --> todo[用户确认后建待办]
  todo --> complete[执行并完成]
  complete --> followup[下次会话回看结果]
  followup --> coach
```

## 设计取舍

- 不把心理推断当成事实；
- 不连续抛出多个问题占用注意力；
- 不在用户未确认时自动创建任务；
- 没有真正值得分析的内容时只做简短确认；
- 教练辅助自我反思，不替代医疗或专业心理服务。
