# Daily 发布素材包

## GitHub Release 标题

Daily v0.1.0：让 AI 读取真实记录，再帮助你行动

## GitHub Release 摘要

Daily 是一个自托管的 AI 个人行动与反思系统。首个公开版本包含：

- 基于待办、计时、日记和笔记的真实周期总结；
- 可编辑并需确认的父子任务单；
- 周、月、年度核心目标与投入对齐检查；
- 从日记出发、最终回到行动承诺的教练闭环；
- 附着在真实任务上的想法与经验沉淀；
- Docker Compose 快速启动和完全虚构的演示数据。

这是面向单用户的早期版本。请先阅读 README 的隐私边界和安全说明。

## 社交平台短文案

我把自己用了几个月的 Daily 开源了。

它不是另一个聊天框，而是一个连接待办、日记、笔记和目标的自托管 AI 系统：

- 回答“上个月做了什么”前先查真实记录；
- 把零散想法拆成可编辑任务单，确认后才写入；
- 用实际计时和完成记录检查目标是否对齐；
- 从日记深挖到行动承诺，再在下次会话跟进。

我最在意的三个原则是：先读数据、写入前确认、没必要时少说。

项目：https://github.com/08163356/daiy-workshop

## 公众号 / 知乎导语

我们已经有很多地方记录生活，却仍然很难回答：“我最近到底把时间花在了什么地方？”这篇文章记录了我如何从几个零散的小工具出发，做出一个能读取真实个人记录、把想法转成行动、再把行动沉淀为经验的 AI 系统，以及我为什么最终决定把它开源。
