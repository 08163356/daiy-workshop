# 隐私边界

Daily 的目标是让个人数据尽量留在自己控制的环境中，但“自托管”不等于“所有数据永不离开设备”。

## 留在本地的数据

- 待办、日记、笔记、目标、计时和经验沉淀；
- 用户画像与会话事件；
- AI Provider 配置和访问密钥；
- 上传图片和导入的个人资料。

这些内容默认存放在 SQLite 数据库或 `user-data/` 中，并由 `.gitignore` 排除。

## 可能发给模型服务商的数据

当你请求 AI 分析、总结、拆任务或教练对话时，系统会发送完成该请求所需的记录片段、用户画像和当前对话。具体保存期限和训练政策由你选择的模型服务商决定。

## 公开演示

公开 Demo 只能使用 `backend/scripts/seed_demo.py` 生成的虚构数据。不要上传真实数据库后再尝试逐条删除，因为备份、日志和缓存仍可能保留内容。

## 开源贡献

提交代码或截图前，请检查：

- 姓名、邮箱、公司、住址、资产、关系与健康信息；
- API Key、Token、Cookie、服务器地址和本机路径；
- 浏览器标签、头像、通知、文件名和图片 EXIF；
- Git 历史中已经删除但仍可恢复的内容。
